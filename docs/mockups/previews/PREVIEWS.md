# Preview images (CC0 only)

Downloaded 2026-10-05 for mockups of the "Dot society" town look. There are four images. All four are CC0 (public domain dedication). Each pack's own licence file was downloaded from the same commit and is stored next to the image, so the licence text travels with the art. All files are unmodified originals, byte for byte. The source URLs are pinned to a commit so they can be re-checked.

Hosts: kenney.nl, itch.io and opengameart.org are blocked from this environment, so the files come from GitHub repositories that contain each pack's original licence file. Those mirrors are third-party copies, not the authors' own distribution points. The authors' pages are listed as "canonical page" for reference, but they could not be opened here.
