## Decisions

**The owner's, on 8 October 2026:**
- spoilage: `skip-expired`;
- the map stays 48 × 28, with placeholder values;
- push after each sub-milestone.

**Agent rulings,** which the owner can overturn:

- **@stdlib may run at runtime outside per-agent loops,** as task 1 step 4 allows, because every probe job passed. No lint ban was added.
- **`mulPpm` drops the plan's ±1 step.** Below 2^53 cents, the quotient stays under 2^34. There, half an ulp is 9.5e-7, below the 1e-6 gap between quotients, so the division never rounds across a whole number. The lead checked the proof.
- **`checkClaims` returns `CENTS_NOT_EXACT`** for NaN or totals beyond 2^53, so that Infinity can't balance against Infinity.
- **`create*` isn't atomic across several `take`s.** A world that doesn't fit is dropped whole, so `layoutWorld` must never catch the throw.
- **The cash primitives allow overdrafts, and `applyFlows` lets balances go negative.** M2 must enforce non-negative cash, and `economy-review` must check it.
- **The table generator** uses `row / 20` for the mean. Day 1,792 of `FADE_1Y` is exactly 0.5 and rounds up, so that table has 1,794 entries.
- **The lint config gained `syntaxBansWithout`,** at the third exemption block. ESLint now ignores `.superpowers/`, where agents keep scratch copies.
- **The doc:** two M0 items stay unticked.
  - The plan-then-apply item also extends the `Math` lint to worldgen and map code.
  - The culture-columns item also documents the layout in `sim-protocol`, which is M0.3 task 2.
- **Estimates stay in days by hand.** `milestone.md` gives the measured factor rather than rewriting every row.
- **M0.3 wave 0 was done by the orchestrator:** the two package manifests, the lockfile, tiers and actions. That way no two builders ever share the lockfile. Each package gains its `typecheck` script with its first source file.
- **The local sim-core rule now allows `Math.clz32`,** which `log2Q16` and the histogram use.
