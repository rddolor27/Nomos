# M1.5 IP gate and playtests

Part of [M1 Lab mode](../milestone.md).

- **Builds:**
  - the IP gate before going public: original or CC0 art only, `assets/LICENSES.md` complete, and "Pokémon" absent from every name and tag (R3). Sprite previews are gitignored review images, so they never ship and need no licence rows;
  - a playtest build of `main` at the dev URL, deployed by a manual run. M1.6 then deploys dev on every push and ships the public release (CI/CD).
- **Needs:** every earlier M1 check, and M0.6's name lint.
- **Exit checks:**
  - in a recognition test, at least 8 of about 10 novices identify each role and each M1 glyph at 2× and 3×, and playtests with colour-blind players and a demographically diverse panel leave no unresolved readability or fairness issue (R3).
